# CCNA

Moduł portalu pod `/apps/ccna/`.

- `index.html` — lekki shell aplikacji i warstwa SEO
- `router.js` — routing URL i obsługa historii
- `legacy.html` — aplikacja kursu, trenerzy i widoki nauki
- `data/terminology.js` — wspólne angielskie nazwy techniczne w polskich materiałach
- `TERMINOLOGY.md` — zasady słownictwa i kontroli treści

Docelowo kod z legacy.html będzie stopniowo dzielony na pliki JS/CSS/data.
